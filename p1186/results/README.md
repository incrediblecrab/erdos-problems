# `results/` — certified artifacts

The colourings and bases here are the inputs to `src/final_check.py`, which re-derives each bound from the stored colouring in exact arithmetic. Stored `phi`/`psi` fields and base `bound` fields are **recomputed, never trusted**: corrupting one bit of a word makes the check exit 1. The SAT records are the exception. The gate re-checks every SAT word in `apfree_k*.json`; `results/lrat_check.json` records external LRAT checks for the UNSAT answers in `safesat_k*.json`: all UNSAT instances for $k=3,4,5$ and 68 of 72 for $k=6$ were accepted by `lrat-check`, while four $k=6$ cases timed out. These SAT results support only the optimality statements in `NOTES.md` §5 and the negative results in §7, and no bound depends on them.

## The claims

`claims.json` is the machine-checked statement of what this repo asserts. Each entry is `{problem, k, bound, beats, beats_random, note}` with `problem` either `"n"` ($\delta_k$, over $\{1,\dots,n\}$) or `"zp"` ($\tilde\delta_k$, over $\mathbb{F}_p$). `beats` is a published value and is `null` where nothing was improved — set for $\delta_5$, $\tilde\delta_4$ and $\tilde\delta_5$ only.

## Colourings

| file | contents |
|---|---|
| `zm_k{3..6}.json` | periodic colourings of $\mathbb{Z}_m$, keyed by $m$ |
| `zm_k5_big.json`, `zm_k4_big.json` | tiling-seeded results at large $m$ |
| `wildcard_k5.json`, `wildcard_k5_deep.json` | the $k=5$ chain, incl. $m=484$ and $m=5324$ |
| `wildcard_k6_deep.json` | the $k=6$ chain, $m=3698$ |
| `n_k{3,4,5}.json` | block colourings of $\{1,\dots,n\}$ |
| `two_k{3,4,5}*.json` | two-scale colourings, incl. the best finite-level $\delta_4$, $2917/209088$ |
| `safebase_k{4..8}.json` | the recursion bases behind the $\delta_4$ to $\delta_8$ claims, written by `src/bases.py` |
| `apfree_k5.json`, `apfree_k6.json` | SAT search for moduli admitting a cyclic $k$-AP-free 2-colouring ($k=6$: $87 \le m \le 240$) |
| `safesat_k{3..6}.json` | exact SAT scan of every $(b, f)$ that would beat the best base: SAT, UNSAT or FORCED |
| `lrat_check.json` | CaDiCaL LRAT proof-check ledger for UNSAT records in `safesat_k{3..6}.json`, generated by `src/prove_unsat.py` and checked by `refs/drat-trim/lrat-check` |
| `weights/` | cached exact AP-weight tables |

Record schema: `k`, `m`, `phi`, `psi`, `psi_float`, `word` (the colouring, as a 0/1 string of length `m`), `ap_free`, and `seeded_from`/`b`/`f`/`r` where relevant. Files are dicts keyed by `m` as a string. Concurrent searches shard by filename and are merged on read, so several files may hold the same $m$; the minimum wins. The base and SAT-scan files are keyed `"b/f"` instead. A base record holds `k`, `b`, `f`, `r`, `word` (which also colours $F$, so the whole word is cyclic AP-free), `source`, and an informational `bound`/`bound_float` that the gate never reads. A scan record holds `k`, `b`, `f`, `status`, plus `symbreak`/`solver` where they differ from the defaults.

## Logs

`*.log` are raw search and verification transcripts, kept for provenance.

- `cosetprobe_k6.log` contains the positive control — the probe rediscovering the known $k=5$ structure ($b=44$, $f=4$, $r=3$) before being applied to $b=86$, since a search too weak to find what is already known is not evidence about what is not.
- `safesat_k{3..6}.log` are the scan transcripts; FORCED instances are stored in the JSON but not printed. `safesat_k6.log` is rendered from the merged `safesat_k6.json`, and its header lists the commands of its seven shards with times, then the runs that were not merged: a budgeted $b=221$ run and the second-solver re-runs of both $b=221$ instances. Only the $(221,17)$ re-run finished (UNSAT); the $(221,13)$ one was stopped after 72 minutes, so $(221,13)$ rests on `cadical195` alone.
- `apfree_k6.log` concatenates its three shards, each under its command line.
- `safesat_selftest.log` holds the symmetry-breaking self-test, the same test with a planted defect, and the stored bases re-solved under symmetry breaking.
- `verify_base_crosscheck.log` compares `src/verify_base` with `safesat.violations` on 21 base variants, 14 of them corrupted.
- `verify_base_k9_12.log` checks the $k = 9, \dots, 12$ words of `NOTES.md` §4, with two controls that must fail.
- `verify_lift_k6_25538.log` counts one level of the $k=6$ recursion directly, with a control.
- `verify_two_k6_226.log` and `verify_two_k6_3698.log` hold the $\{1,\dots,n\}$ residual measurements.
- `final_check_full.log` is the complete validation run.

The `verify_*` logs and `safesat_selftest.log` are one-off runs, not regenerated by `scripts/reproduce.sh`. Each records its command in a `$` line, except `verify_two_k6_3698.log`, which predates that convention.

Nothing here is redistributed source material; see `refs/fetch.sh`.
